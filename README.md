## 📌 About the Project

Self-Bank Management System is a Python project designed to practice object-oriented programming, database connectivity, and SQL operations.

The project uses MySQL to store and manage banking-related information.

## 🛠️ Technologies Used

- Python
- MySQL
- `mysql.connector`
- `colorama`
- Object-Oriented Programming (OOP)

## ✨ Main Features

- Manager and user login functionality
- Customer information management
- Employee management
- Customer account information
- Deposit and withdrawal operations
- Customer record updates and deletion
- Date and time display
- MySQL database connectivity

*Note: Features should be tested before considering the project complete.*

## ⚙️ Requirements

Install Python and MySQL on your computer.

Install the required Python libraries:

```bash
pip install mysql-connector-python colorama
```

## 🚀 How to Run

1. Install Python and MySQL.
2. Install the required libraries.
3. Configure your MySQL connection details.
4. Make sure the database user has the required permissions.
5. Run the Python project:

```bash
python main.py
```

Replace `main.py` with your actual Python filename if it is different.

## 📌 About the Project

The Student Results Management System is a Python-based project developed to manage student records, marks, results, and teacher information using a MySQL database.

The project connects Python with MySQL to store and manage student information. It also uses Pandas to export database records into Excel files.

## 🚀 Features

- MySQL database connectivity
- Student record management
- Teacher information management
- Student marks entry
- Best-five marks calculation
- Total marks and percentage calculation
- Search student records using roll number and roll code
- Update student information
- Export student records to Excel
- Export teacher records to Excel
- Colored terminal output using Colorama
- Date and time handling

## 🛠️ Technologies Used

- Python
- MySQL
- Pandas
- MySQL Connector
- Colorama
- Excel

## ⚙️ Installation

Install the required Python libraries:

```bash
pip install pandas
pip install mysql-connector-python
pip install colorama
```

Make sure MySQL Server is installed and running.

## 🗄️ Database Setup

Create a MySQL database named:

```sql
CREATE DATABASE results;
```

Configure your MySQL connection details in the Python program.

**Important:** Never upload your actual database password or private credentials to GitHub.

## ▶️ How to Run

1. Install Python.
2. Install MySQL Server.
3. Install the required Python libraries.
4. Configure your MySQL database connection.
5. Run the Python file:

```bash
python main.py
```
